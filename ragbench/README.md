# RAGBench Track — Domain-Wise RAG Pipeline Benchmarking

Implements the RAGBench side of the capstone: build a full retrieval pipeline
(chunking → embedding → indexing) over the test split of
[`galileo-ai/ragbench`](https://huggingface.co/datasets/rungalileo/ragbench)
across 5 real-world domains, then benchmark it end-to-end using the TRACe
framework (Relevance, Utilization, Adherence, Completeness).

This directory only contains the **data-preparation pipeline** (Colab
notebooks that produce chunks, embeddings, and FAISS indexes). The retrieval
experiments, TRACe scoring, and the interactive benchmarking dashboard that
consume these artifacts live in the accompanying benchmarking application
(see the parent [README](../README.md) for the full project map).

## 1. Pipeline overview

The four notebooks are numbered and must be run in order — each one persists
its output to Google Drive for the next notebook to pick up:

| Notebook | Purpose | Output |
|---|---|---|
| `01_Prepare_datasets.ipynb` | Downloads the **test** split of `galileo-ai/ragbench` for all 12 datasets across 5 domains (biomedical, legal, finance, support, general) and normalizes them into a unified schema. | `datasets/<domain>/<name>_test.parquet` |
| `02_generate_chunks.ipynb` | Loads the normalized datasets and generates chunks using 3 chunking strategies (`standard`, `metadata`, `small2big`). | `chunks/<domain>/*.pkl`, `chunks/chunk_summary.csv` |
| `03_generate_embeddings.ipynb` | Embeds every chunk set with `BAAI/llm-embedder` on a Colab GPU (12 datasets × 3 chunking methods = 36+ embedding artifacts). | `embeddings/<domain>/*.npz`, `embeddings/embedding_summary.csv` |
| `04_build_faiss_indexes.ipynb` | Builds a FAISS index per domain/chunking/embedding combination for fast dense similarity search. | `indexes/<domain>/*`, `indexes/index_summary.csv` |

## 3. Running the pipeline

These notebooks are designed to run in **Google Colab** with Google Drive
mounted (`/content/drive/MyDrive/RAGBenchmark`), since embedding generation
(`03_generate_embeddings.ipynb`) benefits from a free Colab GPU. To reproduce:

1. Upload the four notebooks to Colab (or open directly from this repo via
   the GitHub "Open in Colab" integration).
2. Run `01_Prepare_datasets.ipynb` end-to-end — installs `datasets`, `pandas`,
   `pyarrow`, `tqdm` and downloads all 12 test-split datasets.
3. Run `02_generate_chunks.ipynb` — installs `nltk` and generates all 3
   chunking strategies for every dataset.
4. Run `03_generate_embeddings.ipynb` on a GPU runtime — installs
   `sentence-transformers`, `transformers`, `accelerate` and embeds every
   chunk set with `BAAI/llm-embedder`.
5. Run `04_build_faiss_indexes.ipynb` — installs `faiss-cpu` and builds one
   FAISS index per domain/chunking/embedding combination.

## 4. What's tracked in this repo

To keep the repository lightweight, only the pipeline **code** (notebooks)
and small **summary manifests** are committed:

```
ragbench/
  01_Prepare_datasets.ipynb
  02_generate_chunks.ipynb
  03_generate_embeddings.ipynb
  04_build_faiss_indexes.ipynb
  chunks/chunk_summary.csv          # which chunk artifacts exist, per domain/strategy
  embeddings/embedding_summary.csv  # which embedding artifacts exist, per domain/model
  indexes/index_summary.csv         # which FAISS indexes exist, per domain
```

The bulky generated artifacts themselves (`datasets/*.parquet`,
`chunks/*.pkl`, `embeddings/*.npz`, `indexes/*`, `judge_cache/`,
`experiments/`) are excluded via `.gitignore` and are regenerated by running
the notebooks above.
